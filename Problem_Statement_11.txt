Edge Device Anomaly Detection (Visual Quality Control) Scenario: A manufacturing line inspects images of parts for defects. Image data accumulates daily, but storage on edge devices is constrained, making dataset management difficult. Core Problem: Version-control image binary files separately from code repositories and automate remote container packaging for edge-compatible inference API engines. Tech Stack: DVC (with MinIO/S3 backend), MLflow, FastAPI, Docker, OpenCV/PyTorch. Deliverable: A light-weight Dockerized inspection container that syncs raw image datasets using DVC and serves an optimized computer vision API.
